# Kodbud Data Science Internship

## Internship Overview
- **Program:** Data Science Internship
- **Organization:** Kodbud
- **Focus:** Data analysis, data visualization, machine learning, and data cleaning
- **Projects completed:** 4 tasks from the internship task list

## Task 2 — Titanic Survival Prediction
- **Objective:** Predict whether a Titanic passenger survived.
- **Work completed:**
  - Loaded and explored the Titanic dataset.
  - Cleaned the data and selected relevant features.
  - Trained a classification model.
  - Reviewed the model’s predictions.
- **Tools:** Python, Pandas, Scikit-learn, Matplotlib
- **Code:** [titanic_prediction.py](https://github.com/vangasrinidh/myprojects/blob/main/titanic_prediction.py)

## Task 5 — Salary Prediction
- **Objective:** Predict salary using information such as experience or job-related data.
- **Work completed:**
  - Prepared the dataset for analysis.
  - Trained a Linear Regression model.
  - Evaluated prediction error using Mean Squared Error.
- **Tools:** Python, Pandas, Scikit-learn, Matplotlib
- **Code:** [salary_prediction.py](https://github.com/vangasrinidh/myprojects/blob/main/salary_prediction.py)
- **Dataset:** [illustrative_salary_data.csv](https://github.com/vangasrinidh/myprojects/blob/main/illustrative_salary_data.csv)
- **Output image:** [salary_prediction.png](https://github.com/vangasrinidh/myprojects/blob/main/salary_prediction.png)
